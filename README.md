# LaboratorioChad - Sistema de Gestión de Laboratorio
**Trabajo Práctico  – Curso de Java**

## Descripción
El sistema **“Laboratorio Chad”** permite registrar y gestionar los experimentos realizados por los investigadores de un laboratorio escolar.  
Cada experimento puede ser **químico o físico**, y el programa ofrece estadísticas, reportes y la posibilidad de exportar los datos de los investigadores a un archivo CSV.

---

## Características y Funcionalidades principales

1. Registrar investigadores
2. Registrar experimentos (químicos o físicos)
3. Listar todos los experimentos registrados
4. Mostrar el total de experimentos exitosos y fallidos
5. Indicar el experimento de mayor duración
6. Generar un reporte con promedio de duración y porcentaje de éxito global
7. Mostrar el investigador que realizó más experimentos
8. Exportar la lista de investigadores a un archivo **CSV**

## Requisitos del Sistema

- Java 21 o superior
- Maven 3.6 o superior
- OpenCSV 5.9
